# Error Declaration

An error declaration is an optional field on an EPCIS event that marks a previous event as erroneous. It is not a separate event type. The Winter protocol defines five event types, and an event can optionally carry an error declaration alongside its type.

This represents a previous event determined to be an error. A new event is created, representing the correction. The data inputs represents the objects used for the corrective event.
